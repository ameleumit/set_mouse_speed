# Set Mouse Speed

- Changes mouse speed when <u>holding/toggling</u> **Ctrl** key.
- Windows only 
- Will not be maintained. 
- Licence: CC BY-NC
- Compile with ´cargo build --no-default-features --features "hold"´ for holding Ctrl or ´cargo build --no-default-features --features "toggle"´ for toggling Ctrl
- Written in Rust
